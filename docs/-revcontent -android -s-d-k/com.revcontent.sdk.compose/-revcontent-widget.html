RevcontentWidget

@Composable
fun RevcontentWidget(widgetId: String, modifier: Modifier = Modifier, publisherId: String = Revcontent.publisherId, siteUrl: String = Revcontent.siteUrl, backgroundColor: Color? = null, scrollState: ScrollState? = null, scrollThrottleMs: Long = 100, onLoaded: () -> Unit = {}, onLinkClicked: (String) -> Unit? = null, onError: (String) -> Unit = {})(source)

Renders a Revcontent widget. Self-sizes its height based on the rendered content and disposes the underlying WebView when it leaves composition.

Minimum usage (after Revcontent.configure has run):

Parameters

widgetId

The Revcontent widget identifier.

modifier

Modifier applied to the widget's container.

publisherId

Optional override for Revcontent.publisherId.

siteUrl

Optional override for Revcontent.siteUrl.

backgroundColor

Optional opaque color baked into the widget body. When null (the default) the WebView and document body are transparent, so the host composable's background shows through. Alpha is ignored.

scrollState

Optional parent scroll state; pass it for viewability tracking.

scrollThrottleMs

Minimum interval between scroll-event injections.

onLoaded

Invoked when the widget has finished its initial render.

onLinkClicked

Invoked when the user taps a recommendation link. When null (the default), the SDK opens the URL in a Chrome Custom Tab. Pass a lambda to take over link handling entirely (e.g. analytics + your own in-app browser).

onError

Invoked with an error message if widget loading fails.
