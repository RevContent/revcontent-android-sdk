Wraps an article screen with Revcontent's back-press interception and "Explore More" bottom-sheet behavior.

RevcontentArticleScaffold(
    articleUrl = currentArticleUrl,
    exploreMore = ExploreMoreConfig(
        widgetId = "286827",
        frequencyCapping = FrequencyCapping.OncePerArticle
    ),
    onNavigateBack = { navController.popBackStack() }
) {
    // your article body
}

The back-press callback registers/unregisters automatically with the composable's lifecycle, so there's no setup or teardown required.

Parameters

onNavigateBack

Invoked when the user navigates back (either directly when there's no explore-more config, or after the explore-more sheet is dismissed).

articleUrl

Used for FrequencyCapping.OncePerArticle. If null and that capping is configured, the sheet falls back to showing once per scaffold instance.

exploreMore

Optional explore-more configuration. If null, back press just calls onNavigateBack.

publisherId

Optional override for Revcontent.publisherId.

siteUrl

Optional override for Revcontent.siteUrl.

content

The article body.
