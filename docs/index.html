Revcontent Android SDK

A Compose-first Android SDK for embedding Revcontent recommendation widgets in publisher apps. It wraps the underlying widget WebView, handles scroll-based viewability tracking, and provides an "Explore More" bottom-sheet flow that can intercept back navigation on article screens.

Status: pre-1.0, distributed via GitHub Packages from a private repo. Coordinates: com.revcontent:revcontent-sdk:<version>.

One-time setup

Call Revcontent.configure(...) once from your Application.onCreate() to set the publisher defaults used by the rest of the SDK:

class MyApplication : Application() {
    override fun onCreate() {
        super.onCreate()
        Revcontent.configure(
            publisherId = "84088",
            siteUrl = "https://app.revcontent.com"
        )
    }
}

Every call site can still override publisherId/siteUrl if you embed widgets from more than one publisher.

Embedding a widget (Compose)

@Composable
fun HomeScreen() {
    val scrollState = rememberScrollState()
    Column(Modifier.fillMaxSize().verticalScroll(scrollState)) {
        // ...your content...
        RevcontentWidget(
            widgetId = "286827",
            scrollState = scrollState,            // enables viewability reporting
            modifier = Modifier.fillMaxWidth(),
            onLoaded = { /* initial render complete */ },
            onLinkClicked = { url -> /* recommendation tapped */ },
            onError = { message -> /* load failed */ }
        )
    }
}

Article screens (Explore More)

RevcontentArticleScaffold registers back-press interception while it's in composition. With an exploreMore config attached, pressing back shows the Explore More bottom sheet first; otherwise it falls straight through to onNavigateBack.

RevcontentArticleScaffold(
    onNavigateBack = onNavigateBack,
    articleUrl = articleUrl,
    exploreMore = ExploreMoreConfig(
        widgetId = "286827",
        title = "Keep on reading",
        frequencyCapping = FrequencyCapping.OncePerArticle
    )
) { /* article body */ }

See com.revcontent.sdk.models.FrequencyCapping for the full set of capping strategies (EveryTime, OncePerSession, OncePerArticle, and duration-based every(...)).
